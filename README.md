## 🚀 Key Features

* 📊 **Pro-Terminal Dashboard:** High-density interface optimized for professional data monitoring and rapid analysis.
* 📈 **Interactive Financial Charts:** Precision time-series visualization using **Chart.js** with gradient fills and live-sliding time axes.
* 🤖 **AI Oracle (Dedicated Page):** A standalone terminal for conversational market analysis and technical thesis generation via **Gemini API**.
* 🗞️ **Live News Ticker:** A high-speed, hardware-accelerated marquee providing peripheral awareness of market alerts.
* ⚡ **60s Data Engine:** Automated state synchronization every minute with visual "flash" cues for price volatility.
* 🎓 **Investor Academy:** Educational modules covering **Contango**, **Backwardation**, and **Inflation Hedging**.

## 🎨 Design System & UI Philosophy

The terminal is engineered with a **"High-Density"** philosophy—inspired by Bloomberg and TradingView—prioritizing data throughput over whitespace.

* **Color Palette:** Deep Slate-950 (`#020617`) background for reduced eye strain during long-duration monitoring.
* **Typography:** A blend of **Inter** for UI clarity and **JetBrains Mono** for technical data precision.
* **Visual Reactivity:** Elements pulse with **Emerald-400** (Bullish) or **Rose-500** (Bearish) overlays during automated data refreshes to signal market direction instantly.

## 🧠 AI & Data Intelligence

Market Miner transforms raw metrics into actionable narrative intelligence:

1.  **Market Thesis Generator:** Distills technical factors (RSI, DXY, CPI) into executive-level summaries.
2.  **Contextual Chatbot:** A persistent "Senior Strategist" persona that analyzes the current dashboard data to answer complex user queries.
3.  **Volatility Simulation:** A math-based algorithm that simulates realistic commodity price action within ±0.2% ranges for live demonstration.

## 📦 Getting Started

As a performance-optimized SPA, **Market Miner** requires zero installation or server-side dependencies.

1.  **Clone the Repository:**
    ```bash
    git clone https://github.com/yourusername/market-miner.git
    ```
2.  **Launch:**
    Open `index.html` in any modern web browser (Chrome/Edge/Safari).
3.  **API Integration:**
    To activate the AI Oracle, insert your Gemini API key into the `triggerAIInsight` function within the script tag.
